# Build 서브에이전트 지침: 2048 게임

## 역할
승인된 계획서 `apps/2048/spec.md`대로 2048 웹앱을 **구현**한다.

## 수정 허용 범위 (이 범위만 수정한다)
새로 만들 파일은 정확히 아래 네 개다.
- `apps/2048/index.html`
- `apps/2048/style.css`
- `apps/2048/game.js`
- `apps/2048/main.js`

그 밖의 모든 파일은 읽기만 한다. 특히 아래는 수정하거나 지우지 않는다.
- 블로그 파일: `index.html`(루트), `post.html`, `css/`, `js/`, `posts/`, `images/`
- `CLAUDE.md`, `.claude/`, `apps/2048/spec.md`, `apps/2048/agent-*.md`
- `apps/2048/review.md`는 만들지 않는다 (Review 단계에서 다른 에이전트가 쓴다).

## 하지 않을 것
- 서버를 시작하지 않는다. 브라우저 검증은 Review 단계에서 한다.
- git 명령을 실행하지 않는다.
- 파일을 삭제하지 않는다.
- 외부 라이브러리, CDN, 웹 폰트를 쓰지 않는다.

## 먼저 읽을 것
- `apps/2048/spec.md` (전체. 특히 확정된 결정, 5~7장)
- `CLAUDE.md` (웹앱 규칙)
- `css/theme.css`, `js/theme.js`, `index.html`(루트) — 테마 처리와 코딩 스타일 참고용

## 확정된 결정 (spec.md 상단과 같음)
1. 되돌리기: 1단계만 포함. 되돌리면 점수도 함께 복원한다. 이동이 성립한 직후에만 저장하고, 되돌린 뒤에는 새 이동 전까지 다시 되돌릴 수 없다. 새 게임이면 초기화한다.
2. 진행 중인 판 자동 저장: 하지 않는다. 최고 점수만 저장한다.
3. 블로그 카드 미리보기용 `?preview` 모드를 앱에 구현한다. spec.md 8장대로 헤더/안내/버튼을 숨기고 보드만 고정된 예시 배치로 보여 주며, 키보드와 터치 입력을 받지 않고, 저장된 최고 점수를 읽지도 쓰지도 않는다.
4. 새 게임 버튼은 확인창 없이 즉시 시작한다.
5. 방향키와 WASD를 지원한다. 화면 방향 버튼(D-pad)은 만들지 않는다.
6. 2048 달성 시 "계속하기"와 "새 게임"을 보여 주고, 안내는 한 판에 한 번만 띄운다.

## 구현 요구사항
- spec.md의 게임 규칙, 점수판(현재/최고/이번 이동 `+N`), 입력(키보드, 스와이프), 화면 설계, 색상 표를 따른다.
- `game.js`는 DOM에 접근하지 않는 순수 로직이다. 보드 이동/합치기, 점수 계산, 새 타일 생성, 승리·게임 오버 판정을 담고, 난수는 주입할 수 있게 해서 확인하기 쉽게 만든다(기본은 `Math.random`).
- `main.js`는 렌더링, 입력, 점수 저장(`localStorage` 키 `2048:best`, 접근 실패는 `try/catch`로 무시), 오버레이를 맡는다.
- 두 파일은 ES 모듈로 연결하고 전역 변수를 만들지 않는다.
- 접근성: 점수 영역 `aria-live="polite"`, 버튼은 실제 `<button>`, 타일 보드에는 `role`과 `aria-label`로 현재 상태를 알린다. `prefers-reduced-motion`에서는 애니메이션을 줄인다.
- 모바일: viewport 메타 필수, 375px 폭에서 가로 스크롤 없음, 보드 `touch-action: none`, 터치 대상 44×44px 이상, 본문 글자 16px 이상.
- 테마: `<head>`에서 CSS보다 먼저 실행하는 인라인 스크립트로 `localStorage['theme']`(`light`/`dark`)를 읽어 `<html data-theme>`에 적용한다. 값이 없으면 `prefers-color-scheme`을 따른다. 블로그의 `css/theme.css`는 참조하지 않고 같은 변수를 `style.css`에 복제한다.
- 앱 상단에 "← 블로그" 링크(`../../index.html`)를 둔다.
- 코딩 규칙: 공백 2칸, 세미콜론, 작은따옴표, 클래스 `kebab-case`, 변수·함수 `camelCase`, 주석은 한국어, 식별자는 영어.

## 완료 전 자체 점검 (실행 없이 코드를 다시 읽어서 확인)
- `slideLine`이 `[2,2,2,2]`→`[4,4,0,0]`, `[4,2,2,0]`→`[4,4,0,0]`, `[2,2,2,0]`→`[4,2,0,0]`, `[2,0,2,4]`→`[4,4,0,0]`이 되는지
- 변화 없는 이동에서 새 타일과 점수가 바뀌지 않는지
- 스크립트·스타일·링크 경로가 `apps/2048/` 기준으로 올바른지
