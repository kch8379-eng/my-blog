Claude Code와 함께 블로그를 만들면서 웹페이지가 세 가지 언어로 나뉘어 있다는 것을 배웠습니다. 각각이 어떤 일을 맡는지 정리해 둡니다.

## 한 줄 요약

| 언어 | 역할 | 비유 |
| :--- | :--- | :--- |
| HTML | 페이지의 내용과 구조 | 건물의 뼈대 |
| CSS | 색, 글자, 배치 같은 겉모습 | 인테리어 |
| JavaScript | 클릭하면 반응하는 동작 | 전기와 스위치 |

## HTML: 무엇이 있는지

HTML은 페이지에 **무엇이 들어가는지**를 적습니다. 제목, 문단, 버튼, 링크가 모두 HTML 태그입니다.

이 블로그에서는 `index.html`이 글 목록 페이지의 뼈대이고, `post.html`이 글 읽기 페이지의 뼈대입니다. `header`, `main`, `article` 같은 태그로 영역의 의미를 알려 줍니다.

## CSS: 어떻게 보이는지

CSS는 HTML이 **어떻게 보일지**를 정합니다. 색, 글자 크기, 여백, 화면 크기에 따른 배치가 여기에 속합니다.

- `css/style.css`는 본문 폭, 줄 간격, 표와 코드 블록의 모양을 정합니다.
- `css/theme.css`는 라이트 모드와 다크 모드의 색을 변수로 모아 둡니다.
- 모바일에서도 잘 보이게 하는 일도 CSS가 맡습니다.

```css
:root[data-theme='dark'] {
  --bg: #14171c;
  --text: #e6e8eb;
}
```

색을 변수로 한 곳에 모아 두니, 다크 모드로 바꿀 때 변수 값만 바꾸면 됩니다.

## JavaScript: 어떻게 움직이는지

JavaScript는 페이지가 **사용자의 행동에 반응하게** 합니다.

- `js/theme.js`는 버튼을 누르면 다크 모드로 바꾸고, 선택한 모드를 기억합니다.
- `js/blog.js`는 글 목록 파일을 불러와 목록을 그리고, 글을 열 때 마크다운 파일을 가져옵니다.
- `js/markdown.js`는 마크다운 글을 HTML로 바꿔 줍니다.

## 함께 일하는 모습

글 하나를 읽을 때 세 가지가 이어서 일합니다.

1. HTML이 빈 자리(제목, 본문 영역)를 만들어 둡니다.
2. JavaScript가 마크다운 파일을 가져와 그 자리에 채웁니다.
3. CSS가 채워진 내용을 읽기 좋은 모양으로 꾸밉니다.

## 느낀 점

- 내용, 모양, 동작을 나눠서 생각하니 어디를 고쳐야 할지 찾기 쉬웠습니다.
- 색을 바꾸고 싶으면 CSS, 글을 더 불러오고 싶으면 JavaScript, 영역을 추가하고 싶으면 HTML을 보면 됩니다.
- 프레임워크 없이 이 세 가지만으로도 블로그를 만들 수 있었습니다.
