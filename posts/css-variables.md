이 블로그는 라이트/다크 모드를 지원합니다. 색을 하나하나 고치지 않고도 테마를 바꿀 수 있는 비결이 **CSS 변수**입니다.

## CSS 변수란?

자주 쓰는 값에 이름을 붙여 두고 여러 곳에서 불러 쓰는 기능입니다. 이름은 `--`로 시작하고, 쓸 때는 `var()`로 부릅니다.

## 이 블로그의 예

`css/theme.css`에 색을 변수로 정의해 둡니다.

```css
:root {
  --bg: #ffffff;
  --text: #1f2328;
}

:root[data-theme='dark'] {
  --bg: #14171c;
  --text: #e6e8eb;
}
```

그리고 `css/style.css`에서는 색 값 대신 변수를 씁니다.

```css
body {
  background: var(--bg);
  color: var(--text);
}
```

## 왜 편할까?

- 색을 바꾸고 싶으면 변수 값 한 곳만 고치면 됩니다.
- `<html data-theme="dark">`처럼 속성만 바꿔도 변수 값이 통째로 바뀌어 모든 화면에 반영됩니다.

| 방식 | 색을 바꿀 때 |
| :--- | :--- |
| 색 값을 직접 입력 | 쓴 곳을 전부 찾아 수정 |
| CSS 변수 사용 | 변수 정의 한 곳만 수정 |

## 정리

CSS 변수는 값을 한 번 정의하고 여러 번 재사용하게 해 주는 도구입니다. 테마처럼 한꺼번에 바뀌는 디자인에 특히 잘 맞습니다.
