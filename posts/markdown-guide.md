이 글은 지원하는 문법이 두 테마와 모바일 화면에서 제대로 보이는지 확인하는 용도입니다.

## 텍스트 꾸미기

**굵게**, *기울임*, ~~취소선~~, `인라인 코드`를 쓸 수 있습니다. snake_case_name 같은 단어는 기울임으로 바뀌지 않습니다.

[외부 링크](https://developer.mozilla.org)와 [내부 링크](index.html)도 됩니다.

### 목록

- 첫 번째 항목
- 두 번째 항목
  - 중첩된 항목
  - 또 다른 중첩 항목
- 세 번째 항목

1. 순서가 있는 항목
2. 두 번째 항목
3. 세 번째 항목

- [x] 완료한 일
- [ ] 아직 안 한 일

### 인용문

> 읽기 좋은 글은 여백에서 시작합니다.
>
> 인용문 안에서도 **서식**을 쓸 수 있습니다.

## 코드 블록

```js
async function loadPost(slug) {
  const response = await fetch(`posts/${slug}.md`);
  return response.text();
}
```

아주 긴 줄은 화면 밖으로 넘치지 않고 코드 블록 안에서 가로로 스크롤됩니다.

```text
이 줄은 모바일 화면보다 훨씬 길어서 가로 스크롤이 생기는지 확인하기 위한 매우 긴 한 줄짜리 코드입니다. 0123456789 0123456789 0123456789
```

## 표

| 문법 | 결과 | 비고 |
| :--- | :---: | ---: |
| `**굵게**` | **굵게** | 강조 |
| `*기울임*` | *기울임* | 보조 강조 |
| `~~취소선~~` | ~~취소선~~ | 삭제 |
